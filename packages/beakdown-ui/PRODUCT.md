# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

AI coding agents preparing data pipelines or app/website investigations, and the humans inspecting their evidence and approving their work.

## Product Purpose

Make agent work visually inspectable before the human lets the agent proceed. The user explicitly requested screenshot investigations and executable data pipelines displayed together in an intuitive workspace.

## Operating Context

A local browser canvas served by a loopback daemon, reached through an MCP tool or a review CLI. REA captures original application evidence. DuckDB runs read-only transformations with bounded table previews.

## Capabilities and Constraints

Real screenshots, annotated findings, confidence and provenance, SQL DAG execution, Arrow previews, query edits, human corrections, report export and revision-checked approval. Data computation and navigation relationships must be distinguished. No fabricated outputs or inferred backend facts. Sessions expire after one hour; saved input manifests can recreate them. Production changes remain the agent's responsibility.

## Brand Commitments

Beakdown. The user explicitly selected their shared Starchy Gooey system: Geist typography, neutral drafting ground, black ink, signal red, 34px panel glass, 20px pane glass, and fluid droplet-fusion controls. Public project documentation does not name the inspiration product or the local host workspace.

## Evidence on Hand

A real website investigation exists locally with screenshots and evidence-linked findings. It is private working material, not a public demo asset. The repository also has an explicitly fictional local demo and actual captures of that demo.

## Product Principles

- Show evidence beside the transformations that operate on it.
- Make the connection between source and result actionable in both directions.
- Keep observations, inferences and unanswered questions distinct.
- Preserve legibility of screenshots and tables while navigation expresses the visual material.
